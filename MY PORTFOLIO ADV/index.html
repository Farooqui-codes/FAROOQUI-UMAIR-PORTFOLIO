Case Study: PROBLEM-X
Flagship Full-Stack Project

PROBLEM-X: Smart City Civic Grievance Management

An end-to-end civic complaint portal that enables citizens to report local municipal issues (potholes, broken street lights, pipeline bursts, drainage problems) and track their resolution progress transparently.

Visit Live App View GitHub Repo

The Problem

In many municipalities, reporting civic issues like broken streetlights or damaged roads is complicated. Complaints submitted manually or through phone lines often get delayed without any tracking number or accountability for citizens.

The Solution

PROBLEM-X provides a direct, online portal where any citizen can select a category, upload photo evidence, provide location details, and submit a grievance. The system generates an immediate tracking status and routes the complaint to the relevant city department.

Technical Architecture

  • Frontend: Semantic HTML5, modern CSS3 layout (Flexbox/Grid), and vanilla JavaScript for dynamic client-side validation.
  • Backend: Node.js and Express RESTful API handling complaint routing, form data parsing, and status queries.
  • Database: MySQL database schema with relational tables for complaints, categories, department assignments, and resolution stages.
  • Deployment: Hosted on Render with production environment variables and continuous Git delivery.

Key Features Built

  • Citizen complaint filing with image attachment & location
  • Real-time status stages (Pending, In Progress, Resolved)
  • Administrative overview & grievance categorization
  • Direct helpline & WhatsApp query integration
